# Nossas Finanças

Controle financeiro simples para casal: lançamentos, fotos de comprovantes com leitura automática (OCR), importação de extrato (OFX/CSV), metas de economia, consultor com dicas e sincronização entre dois celulares via Firebase.

- App: `index.html` (arquivo único, sem build)
- Sincronização: veja [CONFIGURAR-FIREBASE.md](CONFIGURAR-FIREBASE.md)
- Os dados ficam no aparelho (e no seu projeto Firebase, se ligar a sincronização). Nada é guardado neste repositório.
